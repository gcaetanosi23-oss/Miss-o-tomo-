# Manual rápido do professor

1. O administrador configura a OAuth App e a lista `allowedTeachers` em `auth-config.js`.
2. Abra o site e selecione **Área do Professor**.
3. Clique em **Continuar com GitHub**, abra a página indicada e informe o código temporário.
4. Após a autorização, o painel apresenta os dados salvos no navegador atual. Será necessário autenticar novamente ao abrir o painel em outra sessão.
5. Use **Exportar relatório CSV** para baixar o resumo dos três slots.

## Limites atuais

- Não há cadastro de turmas ou alunos identificados; os slots são perfis locais anônimos.
- Não há coleta automática de dados de outros dispositivos.
- Limpar os dados do navegador pode apagar o progresso local.
- O painel é demonstrativo/administrativo local, não um sistema escolar com controle de acesso seguro.
